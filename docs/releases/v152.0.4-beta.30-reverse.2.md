# Camoufox Reverse 152.0.4 beta.30 — reverse.2

This is an opt-in prerelease based on upstream Camoufox
[`v152.0.4-beta.30`](https://github.com/daijro/camoufox/releases/tag/v152.0.4-beta.30).
It does not replace the existing Firefox 135 reverse build or change the
upstream Camoufox default channel.

## Added

- Forward-port the engine-level PropertyTracer to Firefox 152.
- Preserve the existing control-file and JSONL event protocol consumed by
  `camoufox-reverse-mcp`.
- Cover 75 DOM/Web API access sites, including the Firefox 152 WebGL extension
  overload and the moved `AudioContext.sampleRate` getter.
- Include `camoufox-reverse-capabilities.json` and a legacy-compatible,
  UTF-8/no-BOM `version.json` in every archive.

## Build safety

- The injector is fail-closed: missing files, ambiguous overloads, partial
  markers, duplicate sites, and version mismatches stop the build.
- A real Firefox 152.0.4 source tree passed `check`, `apply`, and `verify` with
  all 75 sites.
- Packaging uses the upstream beta.30 build and package pipeline rather than
  the legacy Firefox 135 staging scripts.
- Every release publishes SHA256SUMS and BUILD-MANIFEST.json.

## Performance note

Tracing is disabled by default. When enabled, the current protocol appends each
event synchronously under a mutex; very high-volume getter traces can perturb
page timing. Keep sessions short, use object filters, and retain the configured
event cap for timing-sensitive analysis.

## Compatibility

- Supported MCP: `camoufox-reverse-mcp >= 1.3.0`.
- Recommended Python wrapper: Camoufox 0.5.x with side-by-side versioned cache.
- Existing Camoufox 0.4.x/Firefox 135 users can keep their current flat cache
  and omit `browser_version`; no automatic migration is performed by the MCP.
- Official Camoufox builds continue to support all regular MCP tools, but do
  not expose PropertyTracer.

## Required official build

MCP v1.3.0 requires the selected reverse build and the active official browser
to have the same complete version/build. Upstream beta.30 is a prerelease, so
install and explicitly pin it before selecting the reverse build:

```bash
camoufox fetch official/prerelease/152.0.4-beta.30
camoufox set official/prerelease/152.0.4-beta.30
camoufox active
```

The MCP does not make this persistent configuration change for you.

## Install the reverse build without changing active

Extract the chosen archive beneath the Camoufox cache as:

```text
browsers/whitenightshadow/152.0.4-beta.30-reverse.2/
```

The release also includes a local-only installer that validates SHA256 and the
capability marker, refuses legacy-cache migration, and leaves active config
byte-for-byte unchanged:

```bash
python3 install-camoufox-reverse.py camoufox-152.0.4-beta.30-<platform>.zip \
  --sha256 <value-from-SHA256SUMS>
```

Then launch it explicitly:

```text
launch_browser(
  browser_version="whitenightshadow/152.0.4-beta.30-reverse.2",
  enable_trace=True
)
```
