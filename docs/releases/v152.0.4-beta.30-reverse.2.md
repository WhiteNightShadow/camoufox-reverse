## 版本说明

首次将 PropertyTracer 迁移到 Camoufox 152，作为不影响现有 Firefox 135 环境的可选预发布版本。

## 主要变更

- 保留既有 control/JSONL 协议，并覆盖 75 个 Gecko DOM/Web API 原生注入点。
- 适配 Firefox 152 的 WebGL 重载与 `AudioContext.sampleRate` 源码位置。
- 每个平台包均包含能力标记和兼容版 `version.json`；Release 同时提供 `SHA256SUMS` 和 `BUILD-MANIFEST.json`。

## 兼容性

- 配套 `camoufox-reverse-mcp >= 1.3.0` 和 Camoufox Python 0.5.x。
- 使用 selector `whitenightshadow/152.0.4-beta.30-reverse.2` 并存安装；不会自动迁移或覆盖旧 0.4/Firefox 135 缓存。
- Trace 默认关闭，只有显式启用时才记录事件。

## 验证

- Firefox 152.0.4 源码通过 75 点注入检查、应用和复核。
- 四端发布包均通过版本、能力标记和 SHA-256 校验。
