## 版本说明

修复 Firefox 152 默认 LSNG 路径下的 `localStorage` 原生追踪，并补充分区存储分支；固定覆盖集由 75 点增至 77 点。

## 主要变更

- 将 `localStorage.getItem/setItem` 迁移到实际运行的 `LSObject.cpp`。
- 增加 `PartitionedLocalStorage.getItem/setItem`，通过 native `site` 区分两条实现路径。
- protocol 1 及 `o/p/k` 字段语义保持兼容，Trace 仍默认关闭。

## 兼容性

- 配套 `camoufox-reverse-mcp v1.4.0` 及以上版本。
- 使用 selector `whitenightshadow/152.0.4-beta.30-reverse.5` 并存安装；安装器不会修改 active 配置或迁移旧 0.4 缓存。
- 持久化的精确 `site` 过滤条件需要更新为新的 `LSObject.cpp` 路径。

## 验证

- 77 个唯一注入点、LSObject 与 PartitionedLocalStorage 路径检查全部通过。
- 四端构建成功；Linux 与 macOS arm64 实包完成真实 HTTP Origin 和 MCP 汇总验证。
