## 版本说明

完善 PropertyTracer 的事件语义、跨进程排序、异步写入和多会话可靠性，保持 75 点覆盖与 protocol 1 兼容。

## 主要变更

- 正确区分 `get`、`set`、`call`，并增加 native site、序列号和统一时间字段。
- 恢复有界异步批处理，关闭会话前排空缓冲区，并隔离每次运行的 Trace 文件。
- 增加进程级启停确认、Windows Unicode 路径支持和异常写入状态上报。

## 兼容性

- 配套 `camoufox-reverse-mcp v1.4.0`；既有 `o/p/v/t/k` 字段和控制协议保持不变。
- 使用 selector `whitenightshadow/152.0.4-beta.30-reverse.4` 并存安装，普通启动仍默认关闭 Trace。
- 固定覆盖集之外的未命中不能作为“属性未访问”的证明。

## 验证

- 四端构建、75 点 fail-closed 注入测试和原生并发控制测试通过。
- Linux 与 macOS arm64 完成 Trace 开关、事件分类、跨进程排序和多会话实机验证。
