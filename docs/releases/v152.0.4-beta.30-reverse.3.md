# Camoufox Reverse 152.0.4 beta.30 — reverse.3

This prerelease keeps the Firefox 152 PropertyTracer runtime and protocol from
`reverse.2`, while making multi-platform builds safe on shared build hosts.
Existing `reverse.2` installations remain supported and do not need to migrate.

## Build reliability

- Honor `MOZBUILD_STATE_PATH` consistently for Mozilla bootstrap state, Linux
  sysroots, the macOS SDK, and the Windows MSVC runtime.
- Keep the default at `~/.mozbuild`, so existing single-build environments are
  unchanged.
- Allow concurrent jobs to use separate absolute state directories instead of
  replacing a shared Clang toolchain while another Firefox build is running.
- Exercise the isolated path in the four-platform release workflow.

## Browser capability

- Upstream remains Camoufox
  [`v152.0.4-beta.30`](https://github.com/daijro/camoufox/releases/tag/v152.0.4-beta.30).
- PropertyTracer protocol remains version 1 with the same 75 Gecko DOM/Web API
  injection sites.
- `version.json` remains `152.0.4` / `beta.30`; the separate capability marker
  identifies this build as `reverse.3`.
- Tracing remains disabled by default and must be explicitly enabled by the MCP.

## Required official build

`camoufox-reverse-mcp` v1.3.0 requires the selected reverse build and active
official browser to have the same complete version/build. Install and pin the
upstream beta.30 prerelease first:

```bash
camoufox fetch official/prerelease/152.0.4-beta.30
camoufox set official/prerelease/152.0.4-beta.30
camoufox active
```

## Side-by-side installation

Download this release's platform archive, `SHA256SUMS`, and
`install-camoufox-reverse.py`, then run:

```bash
python3 install-camoufox-reverse.py camoufox-152.0.4-beta.30-<platform>.zip \
  --sha256 <value-from-SHA256SUMS>
```

The installer verifies the archive and places it under:

```text
browsers/whitenightshadow/152.0.4-beta.30-reverse.3/
```

It does not change the active Camoufox configuration. Select the build for one
MCP launch:

```text
launch_browser(
  browser_version="whitenightshadow/152.0.4-beta.30-reverse.3",
  enable_trace=True
)
```

Use the installer rather than extracting the zip directly. Cross-built zip
files do not reliably preserve executable mode bits; the installer normalizes
them to `0755` after validating the archive. The macOS artifacts are ad-hoc
signed prerelease builds and are not notarized.

## Validation

- The build-tooling and installer suite passes 18 tests, including unset,
  empty, default, and isolated `MOZBUILD_STATE_PATH` behavior.
- An independent Linux build host produced Linux x86_64, Windows x86_64,
  macOS x86_64, and macOS arm64 from the same build-input tree. Every archive
  passed SHA-256, version, capability-marker, 75-hook, and platform-executable
  checks.
- The Linux x86_64 package passed real MCP v1.3.0 launches with tracing off and
  on; tracing captured Navigator, Window, Screen, Canvas, and AudioContext
  accesses without changing the active configuration.
- The remotely built macOS arm64 package was copied back and launched locally
  in headless and headed modes. It reported Firefox 152, captured Canvas,
  AudioContext, and WebGL access paths, and left the user's real Camoufox and
  PropertyTracer caches byte-for-byte unchanged.
