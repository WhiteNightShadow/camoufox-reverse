## 版本说明

通过隔离 Mozilla 构建状态目录，提升 Linux、Windows 和 macOS 并行构建的稳定性；浏览器追踪协议不变。

## 主要变更

- 统一使用 `MOZBUILD_STATE_PATH` 隔离 bootstrap、sysroot、macOS SDK 和 Windows MSVC runtime。
- 默认仍使用 `~/.mozbuild`，不影响现有单任务构建环境。
- PropertyTracer 保持 75 个原生注入点和 protocol 1。

## 兼容性

- 上游仍为 Camoufox `v152.0.4-beta.30`，配套 `camoufox-reverse-mcp v1.3.0`。
- 使用 selector `whitenightshadow/152.0.4-beta.30-reverse.3` 并存安装，不修改 active 配置。

## 验证

- Linux x86_64、Windows x86_64、macOS x86_64 和 macOS arm64 包均通过版本、能力和平台校验。
- Linux 与 macOS arm64 完成真实浏览器 Trace 验证，用户缓存保持不变。
